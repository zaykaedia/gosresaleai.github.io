Инструкция по выдаче цифрового товара

Ручная проверка оплаты.

1. Проверить заказ

Открой заказ, проверь сумму, сеть оплаты и Telegram клиента.

2. Проверить оплату

Для USDT проверь транзакцию. Для карты проверь личный кабинет платёжки.

3. Поменять статус

Поставь «Оплачено», затем отправь доступ к цифровому товару.

4. Выдать доступ

Отправь ссылку/файл/материал клиенту и поставь статус «Выдано».
