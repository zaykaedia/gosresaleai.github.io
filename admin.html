Инструкция менеджеру

Как обрабатывать заявку.

1. Проверить заявку

Посмотри имя, Telegram, тариф, способ оплаты и цель человека.

2. Ответить в Telegram

Напиши человеку, подтверди тариф и отправь актуальные реквизиты.

3. После оплаты

Поменяй статус на «Оплачено» и отправь доступ к материалам.

4. Если не отвечает

Поставь статус «В работе» и вернись к заявке позже.

Как сделать настоящую админку

Для реального проекта нужно подключить базу и авторизацию.

Вариант 1: Firebase

Firebase Authentication + Firestore. Быстро, удобно, подходит для заявок и контента.

Вариант 2: Supabase

Auth + PostgreSQL + Storage. Хороший вариант для более взрослого проекта.

Вариант 3: Node.js backend

Express/Nest + база данных + серверная админка. Максимальный контроль, но сложнее запуск.
