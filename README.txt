GOSRESALE — версия с приветственным экраном и закрытым каталогом

Что добавлено:
1. index.html — основной сайт с полноэкранным анимационным приветствием GOSRESALE.
2. Без входа пользователь видит только стартовый экран с кнопками регистрации/входа.
3. После регистрации или входа приветственный экран автоматически исчезает и открывается основной сайт.
4. Товары, цены, фото, описания и оформление заказа доступны только зарегистрированным пользователям.
5. account.html — личный кабинет пользователя с редактированием профиля и историей заказов.
6. admin.html — админ-панель для управления товарами, заказами, FAQ и пользователями.
7. firestore.rules — правила безопасности Firestore.
8. storage.rules — правила Storage, если файл есть в архиве.

Как установить на GitHub:
1. Распакуй архив.
2. Замени старые файлы сайта на файлы из папки «сайт».
3. Загрузи файлы в свой GitHub-репозиторий.
4. Открой сайт через GitHub Pages.

Что включить в Firebase:
1. Firebase Authentication → Sign-in method → Email/Password → Enable.
2. Firestore Database → Rules → вставь firestore.rules → Publish.
3. Storage → Rules → вставь storage.rules, если используешь фото товаров/аватарки.

Как это работает:
- Новый посетитель открывает сайт и видит красивое приветствие GOSRESALE на весь экран.
- Он нажимает «Создать аккаунт» или «Уже есть аккаунт».
- После регистрации/входа попадает на основной сайт.
- Если пользователь выйдет из аккаунта, сайт снова покажет приветственный экран.
